# PreFlight · 半自动测试系统

一套"学习项目 → 感知改动 → 归纳影响 → 生成用例 → 人工确认执行 → 沉淀资产"的半自动测试系统，用于在多人协作开发场景下，在上线前拦截因自测不足带来的问题。

**项目名释义**：PreFlight = 航空"起飞前检查"（preflight check）。飞行员起飞前必须逐项过检查单——本系统就是上线的检查单，把问题拦在起飞之前。

> ⚠ **操作纪律（2026-09-20 第七轮，05 §10 Q-C 定案）**：在真实 dogfooding 数据（8320 实例）上做任何批量/破坏性操作前——① 先备份元数据库 `data/preflight.db`（WAL 模式下连 `preflight.db-wal/-shm` 一并拷，或先正常停服让它 checkpoint）；② 破坏性写 SQL 只走回滚模式（提交通道=管理员+环境 allow_ddl_commit+二次确认+审计）；③ 删项目/删仓库、DDL 提交、知识包导入覆盖等按钮在真实数据上默认不点，需要时先导出知识包留档。

> ⚠ **两条工程纪律（2026-09-21 第十三轮，由真实卡顿反推）**：① **导入/学习写入必须幂等**——每张知识表都要有唯一键 + `INSERT OR IGNORE`，否则同一份包导两次数据成倍涨，页面直接卡死（`file_bindings` 是最后一个漏网者，V12 已补）；② **常驻列表页与弹屏的每一条反查 SQL 必须有索引**——卡片上千张后"归属仓库"这种 EXISTS/子查询反查会退化到几十秒，加索引前先拿真实数据计时（06 §13）。验证按钮/弹屏时**不许把测试项目留在用户的项目列表里**，用完即删。
>
> ⚠ **第十五轮补的两条（06 §15）**：③ **任何"凭据换发"都要先问"同一枚凭据被并发用两次会怎样"**——持久登录做成"用一次就作废换发"时，同一浏览器的多标签页与并发 fetch 共享同一 cookie，只有一个请求能续上、其余被判未登录，表现就是"有时候突然要重登"；改成**幂等续期**（不换值、不删行，剩余不足阈值才滑动延期）才对。④ **自适应布局的回调里不要再写样式**——文档级 `MutationObserver` 里改样式会自触发成强制同步布局死循环，整页冻结的锅看着像"数据太多"，其实跟数据量无关；量过再定性（最坏真实卡 47 段/20 参数只需 482ms）。派生面板默认只列"本次真的用上的 + 需要人决策的"，其余收进展开。

> ⚠ **动态 SQL 的四条边界（2026-09-21 第十四轮，06 §14.6）**：① `dynamic_body` 是**源码事实**（学习期存语句内层原文），只被**新增列**，不参与结构变更判定——所以重学不会把历史用例批量打成"待复核"；② 条件片段的**判定结果、参数清单、拼出的 SQL 全部在读取期现算**，不落库，因此改 assembler 立即对存量卡生效；③ 判断表达式**只认白名单写法**（`==`/`!=`/`and`/`or`/裸值/字面量比较），`list.size() > 0`、函数调用、括号一律标 `unknown` 交给人工【强制包含】——**宁可不拼也不猜**；④ `${}` 是**字面替换**，填的值本身要写成 SQL 片段（如 `order by xxx`），界面上已明说。

## 形态与工具链

- **单体服务**：Java 21 + Spring Boot，单个 fat jar 同载 REST、前端页面、定时任务；**不使用 Docker**，服务端口 **8320**。
- **部署**：自包含部署包（jar + 外部驱动 + 启停脚本 + 数据/日志目录），目标机零环境安装；`dev\jre\` 是约定的便携 JRE 位（本机走 `tools\` 里的 JDK，未预置 JRE）。
- **工具链**：本机使用 `tools/` 目录内 JDK 21（Temurin）+ Maven 3.9.11（华为云镜像），仅在脚本与命令中进程级指定 `JAVA_HOME`，**不影响本机 JDK 1.8 环境与任何系统变量**。`tools/` 体积大、**不随源码发布**；缺失时 `build.bat` 回落到 PATH 上的 `java`/`mvn` 与默认 `~/.m2`。
- 前端为免构建原生 JS SPA（`static/` 下三个文件），打进 jar，**改完要重新 `build.bat package` 并重启才生效**。

## 快速开始

```bat
dev\bin\stop.bat           :: 改代码后先停服（否则构建能成功，但拷到 dev\lib 会被占用而失败＝部署没成）
dev\bin\build.bat package  :: 构建（首次需联网下载依赖；必须显式给 goal。本仓当前无 src\test，不跑测试）
dev\bin\start.bat          :: 启动
:: 浏览器打开 http://localhost:8320
dev\bin\stop.bat           :: 停止
```

## 关键设计原则

1. LLM 只做归纳与生成，影响分析与请求执行走确定性工程，保证可靠与可离线。
2. 知识库是一等公民：SQLite + 文件，一个 zip 包即可迁移。
3. 半自动 = 系统建议、人拍板：所有 LLM 产物先草稿后确认，带置信度；不强制全测，未测项留痕可回看。
4. 安全内置：系统自身 SQL 全参数绑定、直测默认事务回滚、凭据 AES-GCM 加密、全程审计。
5. 自包含交付：部署包自带便携 JRE 与启停脚本，目标机解压即用、零环境修改。
